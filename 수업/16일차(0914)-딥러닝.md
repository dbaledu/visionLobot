## 딥러닝을 이용한 선형회귀 분석

- 실습파일 : py0914_딥러닝_sequential.ipynb
- 데이터셋 : **ozone.csv**(오존 농도와 기상 정보의 관계를 분석)
- **Solar.R(태양 복사량)을 이용해서 Ozone(오존 농도) 예측**
- 여러 센서(독립변수) 정보를 입력받아 하나의 결과(종속변수)를 예측한다는 점에서, 자율주행에서 센서 데이터를 이용해 속도나 조향각을 예측하는 회귀 문제와 같은 구조로 이해할 수 있습니다.

#### 전체 소스

```python
import pandas as pd
import numpy as np

from sklearn.preprocessing import MinMaxScaler

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Flatten
from tensorflow.keras.optimizers import SGD

df = pd.read_csv('/content/drive/MyDrive/Colab Notebooks/ozone.csv')

# 필요한 컬럼만 추출
columns = ['Ozone','Temp']
df2 = df[columns]

# 결측값이 있는 행을 제거
df3 = df2.dropna()

# 모든 결측값이 제거되었는지 확인
print(df3.isnull().sum())

# 독립변수와 종속변수 분리
X = df3.loc[ : 'Temp'].values.reshape(-1,1)   # numpy ndarray 형식으로 변환
y = df3.loc[ : 'Ozone'].values.reshape(-1,1)

# 0~1 범위로 정규화(Min-Max Scaling)
scaler_x = MinMaxScaler()  #스케일러 객체 생성
scaler_y = MinMaxScaler()  # X와 y는 서로 다른 범위를 가지기 때문에 따로 생성. 

# 각각의 최소·최대값이 다르므로 따로 학습해야 함.
X_norm = scaler_x.fit_transform(X)  # 테스트 데이터 정규화 
y_norm = scaler_y.fit_transform(y)  # 라벨(종속변수) 정규화

# 순차 신경망 모델을 생성
model = Sequential()

# 입력특성 수 지정
model.add(Flatten(input_shape=(1,)))   

# 선형회귀에서는 출력은 1개, 활성화함수는 linear 
model.add(Dense(units=1, activation='linear'))

# 모델 컴파일
model.compile(optimizer=SGD(learning_rate=1e-2), loss='mse')

# 모델 학습
model.fit(X_norm, y_norm, epochs=500, verbose=1)

# 예측 데이터도 정규화해야함
# 70 화씨 온도에 대한 오존을 예측
test_data = np.array([[70]])
result = model.predict(scaler_x.transform(test_data)) 

# 정규화된 예측을 오존의 원래 스케일로 연변환
print('예측된 오존 지수', scaler_y.inverse_transform(result))
```

#### 정규화

```python
# 0~1 범위로 정규화(Min-Max Scaling)
scaler_x = MinMaxScaler()  #스케일러 객체 생성
scaler_y = MinMaxScaler()  # X와 y는 각각의 최소·최대값이 다르므로 따로 학습. 

# 각각의 최소·최대값이 다르므로 따로 학습해야 함.
X_norm = scaler_x.fit_transform(X)  # 테스트 데이터(X)학습하고 정규화 
y_norm = scaler_y.fit_transform(y)  # 라벨(종속변수)을 학습하 정규화
```

- MinMaxScaler : 0~1 범위로 정규화(Min-Max Scaling)
- 딥러닝에서 정규화는 필수
- 기본 범위는 0~1이며, 필요하면 `MinMaxScaler(feature_range=(-1, 1))`처럼 범위를 변경할 수도 있습니다.
- X 데이터는 fit_transform
    - fit : `X`의 최소값과 최대값을 기억합니다.
    - transfrm : fit에 만들어진 공식을 사용하여 0~1 사이의 값으로 변환
- y 데이터는 transform 만 해야 함.

> 테스트 데이터에 `fit()`을 하면 데이터 누수(Data Leakage) 가 발생할 수 있으므로 `transform()`만 사용하는 것이 원칙. 학습 데이터의 min, max와 테스트 데이터의 min, max가 다를 수 있다

- `fit_transform()`과 `transform()`을 구분하는 이유
    - `fit_transform(X_train)` : 훈련 데이터의 최솟값과 최댓값을 학습(fit) 하고 스케일링까지 수행
    - `transform(X_test)` : 훈련 데이터에서 학습한 최솟값·최댓값을 그대로 사용하여 테스트 데이터를 변환

|함수|역할|언제 사용?|
|---|---|---|
|`fit()`|최소·최대값 학습|훈련 데이터|
|`transform()`|학습한 기준으로 변환|테스트 데이터|
|`fit_transform()`|학습 + 변환|훈련 데이터|
|`inverse_transform()`|원래 값으로 복원|예측 결과 해석 시|

## 이진분류 MLP(은닉층 이용)

- 실습파 : `py0914_3_MLP_은닉층.ipynb`
- 데이터셋 : admission.csv
- `gre(대학원 입학시험)` 와 `gpa(학부 GPA 평균학)` 를 이용하여 `admin(입학여부)` 예측

#### 전체 소스

```python
import pandas as pd
import numpy as np

from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Flatten
from tensorflow.keras.optimizers import SGD

# data 로드
df = pd.read_csv('/content/drive/MyDrive/Colab Notebooks/admission.csv')

# 독립변수, 종속변수 분리
X = df[['gre','gpa']].values
y = df['admit'].values.reshape(-1,1)

# 학습 데이터, 테스트 데이터 분리
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=123)

# 정규화 :  스케일링  ( y는 정규화 되어 있음. )
scaler = MinMaxScaler()
X_train_norm = scaler.fit_transform(X_train)   # fit은 Scaler가 데이터의 기준값(min, max)을 계산해서 기억한다는 뜻
X_test_norm = scaler.transform(X_test)   # 학습데이터롤 기억된 기준이 있으므로 데이터 변환만 수행

# 순차 신경망(Sequential Neural Network) 모델 객체 생성
model = Sequential()

# add()를 이용해 층을 하나씩 추가
model.add(Flatten(input_shape=(2,)))             # 입력층
model.add(Dense(units=10, activation='relu'))    # 은닉층  Dense는 기둥  units은 뉴런
model.add(Dense(units=1, activation='sigmoid'))  # 출력층  sigmoid : 0과 1에 수렴

model.compile(optimizer=SGD(learning_rate=1e-2), # SGD : 경사하강법
              loss='binary_crossentropy',   # 분류(회귀)
              metrics=['accuracy'])       # 성능평가 혼동함수  accuracy:정밀도

model.summary()

model.fit(X_train_norm,
          y_train,
          epochs=500,
          validation_split=0.3,
          verbose=1)
          
# 모델의 최종 평가
result = model.evaluate(X_test_norm, y_test)          
```

```python
model.add(Flatten(input_shape=(2,)))             # 입력층.

model.add(Dense(units=3, activation='softmax'))  # 출력층 softmax
```

## 나의 추가 학습

#### 머신러닝과 딥러닝 용어 비교

|모델 구조|머신러닝 용어|딥러닝 용어|
|---|---|---|
|`Dense(1, linear)` (은닉층 없음)|선형회귀|선형회귀|
|`Dense(1, sigmoid)` (은닉층 없음)|로지스틱 회귀|로지스틱 회귀|
|`Dense(3, softmax)` (은닉층 없음)|소프트맥스 회귀(다중 로지스틱 회귀)|소프트맥스 회귀|
|은닉층 추가 (`Dense(16, relu)` 등)|-|MLP(다층 퍼셉트론), 신경망|

- **`출력층만 보면`** 어떤 문제를 푸는지 알 수 있습니다.

#### Sequential 신경망 학습과정

① model = Sequential() ← 신경망 틀 생성  
↓  
② model.add() ← 층 추가  
↓  
③ model.compile() ← 학습 방법 설정  
↓  
④ model.fit() ← 학습  
↓  
⑤ model.evaluate() ← 평가  
↓  
⑥ model.predict() ← 예측

#### 딥러닝

입력 데이터  
↓  
순전파(Forward Propagation)  
↓  
예측값  
↓  
Loss 계산  
↓  
Gradient 계산  
↓  
역전파(Backpropagation)  
↓  
가중치 업데이트  
↓  
다시 순전파  
↓  
Loss 감소

↓

↓

↓  
"가중치를 어느 방향으로 바꿔야 하지?"  
↓  
Optimizer  
↓  
가중치 수정

#### 문제별 은닉층 필요성

|문제|은닉층 필요성|
|---|---|
|속도만 보고 정지 여부 판단|없어도 가능|
|GRE·GPA로 합격 여부 예측|없어도 가능 (로지스틱 회귀)|
|Iris 품종 분류|없어도 가능하지만 은닉층을 넣어도 됨|
|차선 인식(OpenCV 영상)|필요|
|사람·차량 객체 인식(CNN)|필수|

선형 문제 → 복잡한 비선형 문제로 갈수록 왜 은닉층이 필요함
