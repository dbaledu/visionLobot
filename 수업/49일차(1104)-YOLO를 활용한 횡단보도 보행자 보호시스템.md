### Convert2Yolo

- https://github.com/ssaru/convert2Yolo.git
- Pascal VOC, COCO 등 서로 다른 객체 검출 데이터셋의 라벨 형식을 YOLO 학습 형식으로 변환해 주는 도구
- 특히 VOCdevkit의 XML 파일을 YOLO 형식의 TXT 파일로 변환
- manifest 파일 생성 - 변환된 이미지들의 전체 경로 저장
- Object Detection annotation Convert to [Yolo Darknet](https://pjreddie.com/darknet/yolo/) Format

```shell
# Convert2Yolo 다운로드
$ !git clone https://github.com/ssaru/convert2Yolo.git

# 라벨 포맷을 YOLO 형식으로 변환
$ cd /content/convert2Yolo && python3 example.py \
--datasets VOC \
--img_path /content/VOCdevkit/VOC2012/JPEGImages/ \
--label /content/VOCdevkit/VOC2012/Annotations/ \
--convert_output_path  /content/VOCdevkit/VOC2012/JPEGImages/ \
--img_type ".jpg" \
--manifest_path ../ \
--cls_list_file ../vocnames.txt
  
# --datasets: 데이터 셋 포맷 타입 -> PASCAL VOC 형식
# --img_path: 원본 이미지 디렉토리 경로
# --label: 원본 객체 위치 정보(바운딩 박스) 정보가 있는 경로
# --convert_output_path: YOLO형식으로 변환하여 저장할 경로
# --img_type: 변환 대상 이밎 포맷
# --manifest_path: 변환된 이미지들의 전체 경로 저장
# --cls_list_file: 클래스명이 저장된 파일 경로
```

VOC XML 형식 (변환 전)

```xml
<object>
    <name>car</name>
    <bndbox>
        <xmin>100</xmin>
        <ymin>120</ymin>
        <xmax>300</xmax>
        <ymax>280</ymax>
    </bndbox>
</object>
```

```
#class_id  x_center  y_center  width    height
14         0.538     0.452     0.36     0.5    
```

#####  mAP@0.5와 mAP@0.5:0.95 의미

- 두 지표 모두 모델이 객체를 얼마나 정확하게 검출했는지 평가하지만, 객체 위치를 얼마나 엄격하게 평가하느냐에 차이가 있습니다.
- IoU는 객체 검출 결과의 위치 정확도를 판단하는 기준
- **mAP@0.5** : IoU 임계값을 0.5로 설정한 mAP
	- IoU가 0.5 이상이면 해당 객체 검출을 정답(True Positive)으로 인정
	- 각 클래스의 AP(Average Precision)를 계산한 후 평균을 구합니다. 사람, 자동차, 버스 등 각 객체별 검출 성능을 평균한 값
- **mAP@0.5:0.95**: oU 임계값을 0.5부터 0.95까지 0.05 간격으로 변경하면서 mAP를 계산하고, 그 결과를 평균한 값
- IoU가 0.5일 때는 어느 정도 박스가 겹치면 정답이지만, IoU가 0.95일 때는 예측 박스가 실제 박스와 거의 정확하게 일치해야 합니다.
##### 두 지표 비교

|구분|mAP@0.5|mAP@0.5:0.95|
|---|---|---|
|IoU 기준|0.5 하나|0.5~0.95, 10개 기준|
|평가 엄격도|상대적으로 낮음|높음|
|박스 위치 정확도|비교적 관대|매우 엄격|
|일반적인 점수|높게 나오는 편|낮게 나오는 편|
|대표 평가 방식|VOC 스타일|COCO 스타일|

**핵심 정리**

- mAP@0.5 = 객체를 찾아내는 전반적인 검출 성능
- mAP@0.5:0.95 = 객체를 찾아내면서 위치까지 얼마나 정교하게 맞추는지 평가하는 성능

```python
# filename : cv1104_2.py
#

import os
import sys
import subprocess
import urllib.request
import torch

def main():
    print(f'phthon 버전:{sys.version}, {sys.version_info}')
    print(f'파이토치 버전:{torch.__version__}')
    print(f'CUDA 사용가능:{torch.cuda.is_available()}')

    base_dir = os.path.dirname(os.path.abspath(__file__))
    yolov7_dir = os.path.join(base_dir, 'yolov7')
    video_path = os.path.join(base_dir, 'data', 'crosswalk_cctv_01.mp4')

    if not os.path.exists(video_path):
        raise FileNotFoundError(f'{video_path} 파일이 존재하지 않습니다.')

    # yolo7 저장소 클론
    if not os.path.exists(yolov7_dir):
        print('yolov7 저장소를 내려받는중...')
        subprocess.run(["git","clone","https://github.com/WongKinYiu/yolov7", yolov7_dir],
        check=True)
    else:
        print('yolov7 폴더가 이미 있습니다.')
    
    # PyTorch 2.6  호환 패치 (현재 설치된 버전은 2.14임)
    exp_path = os.path.join(yolov7_dir, 'models', 'experimental.py')
    if os.path.exists(exp_path):
        with open(exp_path, 'r', encoding='utf-8') as f:
            code = f.read()

    if 'weights_only=False' not in code:
        code = code.replace(
            'torch.load(w, map_location=map_location)',
            'torch.load(w, map_location=map_location, weights_only=False)'
        )
        with open(exp_path, 'w', encoding='utf-8') as f:
            f.write(code)

    # yolo7-tiny.pt 경량 가중치 파일
    # 실제 경로가 맞는지 확인
    weight_url = 'https://github.com/WongKinYiu/yolov7/releases/download/v0.1/yolov7-tiny.pt'
    weight_path =  os.path.join(yolov7_dir, 'yolov7-tiny.pt')    
    if not os.path.exists(weight_path):
        print('yolov7-tiny.pt 를 내려받는중...')
        urllib.request.urlretrieve(weight_url, weight_path)
    else:
        print('yolov7-tiny.pt 파일이 이미 있습니다.')
 
    # 동영상 객체 인식
    detect_cmd = [
        sys.executable,
        'detect.py',
        '--weights', 'yolov7-tiny.pt',
        '--conf','0.25',
        '--img-size','320',
        '--source', video_path,
        '--name', 'crosswalk_cctv_01',
        '--exist-ok', 
        '--view-img',
        '--nosave'
    ]

    subprocess.run(detect_cmd, cwd=yolov7_dir, check=True)
    result_path = os.path.join(yolov7_dir, 'runs', 'detect', 'crosswalk_cctv_01', 'crosswalk_cctv_1.mp4' )  # crosswalk_cctv_1  Test_Video_2
    print('객체 인식 완료. result_path', result_path)
if __name__ == '__main__':
    main()
```
