## **Feature Scaling(특성 스케일링)**

- 표준화(Standardization)는 각 독립변수(Feature)를 **평균 0, 표준편차 1에 가깝게** 변환.
- 정규화(Normalization)는 **데이터의 값 범위를 일정한 범위로 맞추는 스케일링 방법**
- **StandardScaler 가 MinMaxScaler 보다 조금(1~2% 정도 좋음)**
- 데이터 분리 후 과적합을 막기 위해서 표준화

> **StandardScaler = 평균 0, 표준편차 1로 맞춘다.  
> MinMaxScaler = 최솟값 0, 최댓값 1로 맞춘다.**

```python
# 데이터 스케일링(표준화)
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
```

#### 전체소스

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.preprocessing import MinMaxScaler
import numpy as np
import pandas as pd
import scipy.stats as stats
import seaborn as sns
import matplotlib.pyplot as plt

# 사이킷런으로부터 iris 데이터를 불러옴
iris = load_iris()

# 사이킷런 데이터에서 dataFrame 으로 변환
iris_df = pd.DataFrame(data=iris.data, columns=iris.feature_names)
print('iris 원본 평균값: ', iris_df.mean())
print('iris 원본 분산값: ', iris_df.var())

# 표준화하기전 히스토그램
col = 'sepal length (cm)'
plt.figure(figsize=(8,4))
plt.title("Before Standard")
sns.histplot(x=iris_df[col], kde=True)
plt.show()

# 표준화
scaler = StandardScaler()
scaler.fit(iris_df)
iris_scaled = scaler.transform(iris_df)
iris_scaled_df = pd.DataFrame(data=iris_scaled, columns=iris.feature_names)
print('iris 원본 평균값: ', iris_scaled_df.mean())
print('iris 원본 분산값: ', iris_scaled_df.var())
plt.figure(figsize=(8,4))
plt.title("After Normalization")
sns.histplot(x=iris_scaled_df[col], kde=True)
plt.show()

# 정규화
scaler_m = MinMaxScaler()
scaler_m.fit(iris_df)
iris_scaled_m = scaler_m.transform(iris_df)
iris_scaled_m_df = pd.DataFrame(data=iris_scaled_m, columns=iris.feature_names)
print('iris 원본 평균값: ', iris_scaled_m_df.mean())
print('iris 원본 분산값: ', iris_scaled_m_df.var())

plt.figure(figsize=(8,4))
plt.title("After Standard")
sns.histplot(x=iris_scaled_m_df[col], kde=True)
plt.show()
```
