1. while을 이용하여 숫자로 데미지를 입힞 후 체력이 0이 되면 종료하게 만들기

```python
# 1. while True ~ break 이용

stamina = 100
while True:
  print(f'주인공의 체력은 {stamina} 입니다.')
  damage = int(input('얼마의 데미지를 입히겠습니까 : '))
  stamina = stamina - damage
  if stamina <= 0:
    print(f'주인공의 체력은 {stamina}이 되어 종료됩니다!')
    break

#2. while 조건식

while stamina > 0:
  print(f'주인공의 체력은 {stamina} 입니다.')
  damage = int(input('얼마의 데미지를 입히겠습니까 : '))
  stamina = stamina - damage

print(f'주인공의 체력은 {stamina}이 되어 종료됩니다!')
```

1. for문을 이용해서 1 부터 10 까지 합을 구하기

```python
# 합을 저장할 변수가 필요함
# 1부터 증가시키면서 누적해서 합함  

tot = 0
for i in range(1, 11):
  tot += i
print('1부터 10까지의 합은 ' , tot)
```

5. for 문을 이용해서 1 부터 100 사이의 정수 중 5와 7의 배수를 동시에 만족하는 수 출력하기

```python
# 1 ~ 100 반복문 필요          --> for
# 5와 7의 배수 구할 조건문 필요 --> 나머지 연산, 비교연산

print('5 와 7의 공배수 ')
for i in range(1, 101):
  if i % 5 == 0 and i % 7 == 0 :
    print(i, end=' ')
```
