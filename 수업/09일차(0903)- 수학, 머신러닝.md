### 공분산(covariance)

- 자료가 평균값으로부터 얼마나 떨어져 있는지 나타낸것
- 공분산은 단위에 영향을 받아서 확률변수가 큰 값을 다룬다면 공분산도 커지는 문제가 있음 —> 해결책:상관관계

### 상관관계

- 두 변수간의 어떤 선형, 비선형적 관계를 갖고 있는지를 분석하고 두 변수간의 관계의 강도를 상관계수라고 함
- 상관계수(correlation coefficient) : 공분산과 달리 상관계수는 -1 ~ 1 사이에만 존재. 단위에 영향을 받지 않음
- 피어슨 상관계수는 선형적일 때만 상관관계를 제대로 계산

```python
from sklearn.linear_model import LinearRegression   # 선형회귀
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('/content/drive/MyDrive/data/heights.csv')

print(df.size)
print(df.shape)
print(df.dtypes)
print(df.info())

df = pd.read_csv('/content/drive/MyDrive/data/heights.csv')
# BMI 계산
# 1. 키 단위를 in -> m 로 변환
#df['height'] =((df['height'] * 2.54 ) / 100) ** 2

# 2. 몸무게 파운드 -> kg로 변환
# 3. 키를 제곱
# 4. 몸무게를 제곱한 키로 나눈다

# 파운드(lb)와 인치(in) 단위를 사용할 때의 BMI 공식은 703 × 체중(lb) ÷ 키(in)²
df['BMI'] = (703 * df['weight'] ) / (df['height'] ** 2)

# 평균 계산
df.loc['평균'] = df.mean(axis=0)

# 데이터를 가지고 독립변수(X), 종속변수(y)
# 선형회귀모델 -> y = a(가중치)X + b(편차)
X = df['height']  # 독립변수(키) - 인치
y = df['weight']  # 종속변수(몸무게) - 파운드
print(type(y))

plt.scatter(X, y) # 산점도
plt.xlabel = 'height (Inch)'
plt.ylabel = 'weight (Pound)'
plt.show()
# 산점도로 상관 관계 확인

# train_test_split → fit → predict → MSE/R² 평가

# 2. 학습데이터 정규화 : 1차원을 2차원으로 변경
X2 = X.values.reshape(-1, 1)    # Series -> ndarray 변환 (-1,1): 행은 알아서 열은 1개

X_train, X_test, y_train, y_test = train_test_split(
    X2,
    y,
    test_size=0.2,
    random_state=42
)

# 1. 선형회귀모델 생성
model = LinearRegression()

# 3. 모델 학습
# 데이터(2차원), 정답(1차원)
#   독립변수,    종속변수
model.fit(X_train, y_train)

# 4. 예측 : 키 65인치인 사람의 몸무게 예측
preData = [[68]]   # 학습데이터와 같은 구조여야 함
pre_y = model.predict(preData)

print('인공지능 예측 몸무게(파운드): ', pre_y)
# 정답은 아님. 데이터 기준으로 예측
```

```python
R²가 1에 가까움
    → 모델이 임대료 변화를 잘 설명

R²가 0에 가까움
    → 설명력이 낮음

R²가 음수
    → 모델 성능이 매우 좋지 않음
```
