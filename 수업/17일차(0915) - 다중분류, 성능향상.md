# 추가학습

#### 스케일링

- feature 간의 단위가 다르므로 맞춰줌
- **정규화(Normalization)**: 데이터를 일정한 범위(예: 0~1)로 맞추는 것
- **표준화(Standardization)**: 평균 0, 표준편차 1로 맞추는 것

#### 주요 스케일러 비교

|스케일러|변환 방식|특징|이상치 영향|
|---|---|---|---|
|`MinMaxScaler`|0~1 범위|가장 많이 사용하는 정규화|큼|
|`StandardScaler`|평균 0, 표준편차 1|머신러닝 기본|있음|
|`RobustScaler`|중앙값·사분위수|이상치에 강함|작음|
|`MaxAbsScaler`|-1~1 범위|희소행렬에 적합|있음|
|`Normalizer`|벡터 길이를 1로|텍스트·코사인 유사도|보통|
|`PowerTransformer`|정규분포에 가깝게|왜도가 큰 데이터|보통|
|`QuantileTransformer`|균등/정규분포 변환|분포 자체를 변경|매우 강함|

#### MinMaxScaler

사용예

- 신경망(MLP)
- 양수인 경우
- 이미지 픽셀(0~ 255 —> 0~ 1)

#### StandardScaler

공식
![[0915_6.png]]


예시

- 평균보다 작음 → 음수
- 평균 → 0
- 평균보다 큼 → 양

사용예

- SVM
- 로지스틱 회귀
- KNN
- PCA

#### 정규화 vs 표준화

|구분|MinMaxScaler|StandardScaler|
|---|---|---|
|분류|정규화 (Normalization)|표준화 (Standardization)|
|변환 기준|최소값·최대값|평균·표준편차|
|결과 범위|보통 0~1|평균 0, 표준편차 1|
|공식|`(x-min)/(max-min)`|`(x-μ)/σ`|
|이상치 영향|큼|있음(중간 정도)|
|주로 사용|신경망, 이미지|SVM, 로지스틱 회귀, PCA, KNN|

#### 머신러닝에서 어떤 스케일러를 사용할까?

|알고리즘|추천 스케일링|
|---|---|
|선형회귀|StandardScaler|
|로지스틱 회귀|StandardScaler|
|KNN|StandardScaler 또는 MinMaxScaler|
|SVM|StandardScaler|
|신경망(MLP)|MinMaxScaler 또는 StandardScaler|
|Decision Tree|보통 불필요|
|Random Forest|불필요|
|XGBoost|거의 불필요|
|CNN(이미지)|MinMaxScaler(0~1)|

# 회귀 성능평가 지표

오차를 음수와 양수가 상쇄되지 않게 처리하는 방법

MAE·MSE·RMSE는 오차를 처리하는 방식이 서로 다르고, R²는 그 오차를 이용해 모델의 설명력을 나타내는 지표

|지표|풀네임|오차 처리 방법|값의 의미|
|---|---|---|---|
|MAE|Mean Absolute Error|절댓값|작을수록 좋음|
|MSE|Mean Squared Error|제곱|작을수록 좋음|
|RMSE|Root Mean Squared Error|제곱 후 루트|작을수록 좋음|
|R²|Coefficient of Determination|설명력|1에 가까울수록 좋음|

- MAE → 절댓값을 평균낸 오차(해석 쉬움).
- MSE → 오차를 제곱한 평균(큰 오차를 더 크게 벌줌).
- RMSE → MSE에 루트를 씌워 원래 단위로 표현.
- R²(결정계수) → 모델의 설명력(1에 가까울수록 좋음).

#### 언제 어떤 지표를 사용할까?

|상황|추천 지표|
|---|---|
|평균 오차를 쉽게 설명|MAE|
|큰 오차를 중요하게 볼 때|RMSE|
|딥러닝 손실함수|MSE|
|모델 설명력 확인|R²|
