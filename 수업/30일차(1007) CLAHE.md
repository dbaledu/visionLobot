```python
#---------------------------------------------------
# 화질 개선 알고리즘
#---------------------------------------------------
# 1. 선형 밝기/대비 조정
#    - dst = alpha * src + beta
#    - alpha : 대비(대조비),  alpha( >1 대비 증가)
#    - beta : 밝기       beta(+ 밝게 / - 어둡게),
#    - 255 초과 값은 포화(saturation)- 255이상은 255로 지정
#
# 2. 감마 보정 : dst = (src/255)^(1/gamma) * 255
#                     ((i / 255.0) ** (1.0 / gamma)) * 255
#    - 감마값:   
#        1.0 :원본    
#        1.0 < : 어둡게
#        1.0 > : 밝게
#
# 3. 히스토그램 평활화 
#    - 일반 평활화 : 전체 이미지(영상)를 대상으로 적용 -> 노이즈까지 증폭시킬 수 있음
#    - CLAHE(Contrast Limit Adaptive Histogram Equilization: 적응형 히스토그램 평활화)
#      : 타일(국소적, 지역적)으로 적용 -> 적절한 수준으로 노이즈 증폭 억제
#
# 4. 노이즈 제거
#    -  밝기를 올리면 숨어있던 노이즈도 증가하므로 노이즈 제거가 필요
#
# 5. 선명화(sharpening:샤프닝)
#--------------------------------------------------
```

#### LAB 색상공간

- **L = 밝기**, **A/B = 색상 방향**
- 밝기와 색상 정보를 어느 정도 분리해서 다룰 수 있다는 장점

LAB는 색을 다음 3개 값으로 표현합니다.

|채널|의미|쉽게 말하면|값|
|---|---|---|---|
|**L**|Lightness|밝기||
|**A**|Green ↔ Red|초록 ↔ 빨강|_음수면 녹색, 양수면 빨강_|
|**B**|Blue ↔ Yellow|파랑 ↔ 노랑|_음수면 파랑, 양수명 노랑_|

### HLS vs HSV vs LAB

|색공간|채널|핵심 개념|장점|차선 검출|
|---|---|---|---|---|
|**HSV**|H, S, V|색상·채도·밝기|색상 선택이 직관적|⭐⭐⭐⭐|
|**HLS**|H, L, S|색상·밝기·채도|**밝기 조절에 강함**|⭐⭐⭐⭐⭐|
|**LAB**|L, A, B|밝기·색상|**밝기와 색상 분리가 좋음**|⭐⭐⭐⭐|

```python
              색상 선택
                 │
        ┌────────┼────────┐
        ↓        ↓        ↓
       HSV      HLS      LAB
        │        │        │
     색상검출   밝기검출   밝기/색상
        │        │        │
      노란색    흰색      보정/분석
```

- HSV : 무슨 색이지?
- HLS : 무슨색이고 얼마나 밝지
- LAB: 밝기와 색상을 좀 더 분리해서 처리하자

## 선형 밝기/대비조정 (**`convertScaleAbs()` 함수)**

- **cv2.convertScaleAbs(image, alpha=1.0, beta=60)**
- _**dst = abs( alpha * src + beta )**_
    - alpha = 대비, beta=밝기

#### alpha 와 beta 조정에 따른 변화

- _alpha=1.0 유지, **beta를 60증가**: 전체적으로 **60만큼 밝아지지만** 대비(격차)는 변함없이 뿌옇게 표시_
- _**alpha=2.5배**, beta=0: 픽셀 값 간의 **차이(대비)가 커져** 영상이 뚜렷해짐_
- _alpha와 beta를 동시에 올려 **대비와 전체적인 밝기를 둘 다 개선**_
