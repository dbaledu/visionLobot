## 산업용 로봇의 종류

6축다관절, SCARA, Delta Robot, 협동로봇(cobot)

- **주요 로봇 종류다관절 로봇 (Articulated Robot)**: 인간의 팔과 유사한 관절을 지녀 용접, 조립, 도색 등 복잡하고 정밀한 작업에 주로 쓰입니다. **가장 흔한 형태는 6축 로봇**입니다.
- **협동 로봇 (Cobot)**: 안전 장치를 갖추어 별도의 물리적 격리 없이 인간과 같은 공간에서 안전하게 협업할 수 있는 로봇입니다.
- **자율이동로봇 (AMR, Autonomous Mobile Robot)**: **라이다와 센서를 통해 레일 없이 스스로** 주변 환경을 인식하고 최적의 경로를 찾아 물품을 운반하는 물류 로봇입니다.
- **무인운반차 (AGV, Automated Guided Vehicle)**: 바닥에 설치된 마그네틱 라인이나 **마커 등 지정된 경로를 따라** 정해진 물류를 이동시키는 전통적인 **운송 로봇**입니다.
- **직교 로봇 (Cartesian Robot)**: **직선 축을 따라 상하좌우로 이동**하며, 구조가 단순하고 무거운 물건을 옮기거나 부품을 분류하는 작업에 쓰입니다.
- **스카라 로봇 (SCARA Robot)**: **수평 다관절 형태**로 평면상에서 좌우로 빠르게 움직여 소형 부품 조립이나 고속 이송 작업에 적합합니다

**6축의 구성 (6가지 자유도)**공간(3차원)에서의 위치와 자세를 완벽하게 표현하기 위해 다음의 6가지 동작 요소로 이루어집니다.

- **위치 이동 (3축):** X축(앞·뒤), Y축(좌·우), Z축(위·아래) 직선 이동
    
- **회전 각도 (3축):**  
    ◦ **피치(Pitch):** 상하 회전 (고개 끄덕임) 좌우를 잇는 수평 축(**X축**)  
    ◦ **롤(Roll):** 좌우 기울임 (귀를 어깨에 대는 듯한 회전) **기준 축**: 앞뒤를 잇는 정면 축(**Z축**)  
    ◦ **요(Yaw):** 좌우 회전 (도리도리 고개 돌림) 위아래를 잇는 수직 축(**Y축**)
    
- 휴머노이드: 사람처럼 두 팔·두 다리를 가진 로봇으로 사람이 하던 일을 그대로 대신해보자는 역할
    
- 혐동로봇: 사람 옆에서 같이 일하는 로봇팔로, 나사 조이고, 집고, 옮기는 반복작업에 강함
    
- AMR(자율주행 이동로봇): 공장·창고 안을 바퀴로 돌아다니며 운반하는 로봇으로 '사람이 카트로 끌던 동선'을 담당

### CPU GPU NPU TPU 비교

- CPU(Central Processing Unit)
    - **일반적인 컴퓨터 작업.** 범용프로세서
    - 제어유닛, ALU, 레지스터 등의 구성요소
    - Intel, AMD, ARM, IBM
    - 병렬처리에 취약하고 이미지 인식 작업이 느
- GPU(Graphic Processing Unit)
    - **그래픽 작업과 병렬 처리**에 탁월한 성능
    - NVIDIA, AMD, Intelm Qualcomm
- TPU(Tensor Processing Unit)
    - 딥러닝 모델의 가속화를 위해 특별히 개발된 하드웨어. TensorFlow와의 완벽한 조화
    - **벡터 및 행렬 연산**에 특화되어 있으므로 **이미지 인식** 시스템에 사용
    - Google
- NPU(Neural Processong Unit)
    - **인공신경망과 관련된 작업**을 처리하기 위해 설계된 병렬 처리 프로세서
    - 작은 크기와 낮은 전력 소비로 **모바일 기기나 임베디드** 시스템에 사용
