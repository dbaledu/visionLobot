#### 거리 단위
`ONI_PIXEL_FORMAT_DEPTH_1_MM`은 OpenNI2에서 사용하는 Depth 픽셀 데이터 형식입니다.

여기서 `1_MM`은 **Depth 픽셀값 하나의 단위가 1mm(밀리미터)**라는 의미입니다.

## 1. mm와 μm 단위 비교

| 단위      | 명칭     | 미터(m) 환산     |
| ------- | ------ | ------------ |
| m       | 미터     | 1m           |
| mm      | 밀리미터   | 0.001m       |
| μm (um) | 마이크로미터 | 0.000001m    |
| nm      | 나노미터   | 0.000000001m |

단위 관계는 다음과 같습니다.

$1m = 1000mm$

$1mm = 1000\mu m$

$1um = 0.001mm$

참고로 `μm`은 마이크로미터이며, 키보드로 입력할 때 `um`이라고 표기하기도 합니다.
