#### 데이터셋

- 영화 리뷰 감성 분석(Sentiment Analysis)
- keras.datasets.imdb
    - 데이터 수: 총 50,000개의 영화 리뷰
    - 훈련 데이터: 25,000개
    - 테스트 데이터: 25,000개
    - 분류: 이진 분류(Binary Classification)
        - 0 = 부정(Negative)
        - 1 = 긍정(Positive)
    - 리뷰는 이미 전처리되어 단어가 아닌 정수 인덱스(토큰) 로 저장되어 있음.

#### 작업순서

1. 데이터로드
2. 데이터 확인(단어 수, 분포등)
3. pad_sequences. 각 리뷰의 리스트 길이를 일정하게 맞춤
4. 모델 생성
    1. 입력(Embedding) → LSTM | GRU | Bidirectional → 출력(sigmoid)
    2. 입력(Embedding) → Conv1D → MaxPooling1D → LSTM → Dropout → 출력
5. 모델 컴파일
6. callback 객체 생성
    1. ModelCheckpoint : 검증 set에서 손실이 기존의 최고 성능보다 낮아지면 저장
    2. EarlyStopping: 검증 set에서 손신이 더 이상 감소하지 않으면 학습 중단
7. 모델학습(fit)
8. Epoch별 훈련/검증 손실 확인

## LSTM `py0916_2_RNN_LSTM.ipynb`

#### 전체소스

```python
import tensorflow as fl
from tensorflow import keras
import numpy as np
import matplotlib.pyplot as plt
from keras import datasets, layers, models
from keras.datasets import imdb
from keras.utils import pad_sequences

(train_input, train_target), (val_input, val_target) = imdb.load_data(num_words=100)

# 데이터 확인
print(train_input[0])
print(train_target[0])
print(train_input.shape)

# 리뷰 단어수. 각 행의 열의 크기
lengths = np.array([len(x) for x in train_input])
plt.hist(lengths)
plt.xlabel('length')
plt.ylabel('frequency')
plt.show()

#서로 다른 길이의 리스트를 '0' 채워서 같은 길이로 맞춤
train_seq = pad_sequences(train_input, maxlen=100)
val_seq = pad_sequences(val_input, maxlen=100)

model = keras.Sequential()
model.add(keras.layers.Embedding(500, 32, input_length=100))

#------------
# LSTM(Long Short-term Memory)
model.add(keras.layers.LSTM(32, dropout=0.3, recurrent_dropout=0.3))
#-----------

#-----------
# LSTM  -> GRU 모델로 변경
#model.add(keras.layers.GRU(32, dropout=0.3, recurrent_dropout=0.3))
#-----------

#-----------
# 양방향 학습 LSTM
#model.add(keras.layers.Bidirectional(keras.layers.LSTM(32, dropout=0.3, recurrent_dropout=0.3)))
#-----------

#-----------
# CNN + LSTM 혼합 모델
# model.add(keras.layers.Conv1D(32, 5, activation='relu'))
# model.add(keras.layers.MaxPooling1D(2))
# model.add(keras.layers.LSTM(32))  # , dropout=0.3, recurrent_dropout=0.3
# model.add(keras.layers.Dropout(0.3))
#-----------

model.add(keras.layers.Dense(1, activation='sigmoid'))
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.summary() 

# 검증 set에서 손실이 기존의 최고 성능보다 낮아지면 저장
checkpoint_cb = keras.callbacks.ModelCheckpoint('best-simplernn-model.keras')

# 검증 set에서 손신이 더 이상 감소하지 않으면 학습 중단
early_stopping_cb = keras.callbacks.EarlyStopping(patience=5, restore_best_weights=True)

history = model.fit(train_seq, 
                    train_target,
                    epochs=20,
                    batch_size=64,   # 25000 % 64 --> 배치수 390개 -> 390번 가중치 업데이트 . 보통 2의 배수로 지정
                    validation_data=(val_seq, val_target),
                    callbacks=[checkpoint_cb, early_stopping_cb])
                  
# epoch별로 테스트데이터 손실율과 검증 데이터 손실율을 차트로 표시                    
plt.plot(history.history['loss'])
plt.plot(history.history['val_loss'])
plt.xlabel('epoch')
plt.ylabel('loss')
plt.legend(['train_loss', 'val_loss'])
plt.show()                    
```

#### 데이터 로드

```python
(train_input, train_target), (val_input, val_target) = imdb.load_data(num_words=100)
```

- **num_words**
    
    - 리뷰 길이가 아니라 어휘 사전(Vocabulary)의 크기
        
    - 인수를 100으로 지정한 경우
        
        - 등장 빈도가 높은 상위 100개의 단어만 사용하고 그 외의 단어는 2([OOV])로 바뀝니다.
        - OOV : Out Of Vocabulary
        - Keras의 특수 토큰
        
        |인덱스|의미|
        |---|---|
        |`0`|`[PAD]` (패딩)|
        |`1`|`[START]` (문장 시작)|
        |`2`|`[OOV]` (사전에 없는 단어)|
        |`3` 이상|실제 단어|
        
    - 단어 수를 제한하는 이유
        
        - 임베딩 행렬이 커져서 메모리 증가 → 계산량 증가 → 학습 속도 감소
            
            Embedding(500, 128) → 500 × 128 = 64,000 파라미터  
            Embedding(10000, 128) → 10000 × 128 = 1,280,000 파라미터
            
        - 희귀 단어가 증가 → 노이즈가 많아짐
            
    - `num_words`는 어떻게 정할까?
        
        - 단어 길이 분포와 어휘 빈도 분포를 보고 결정 → **90~95 %**
        
        ```python
        lengths = [len(x) for x in train_input]  # 각 리뷰의 단어 수
        print(np.percentile(lengths, 90))   # 90%가 이 길이 이하
        print(np.percentile(lengths, 95))
        print(np.percentile(lengths, 99))
        ```
        
        - 실무에서는 데이터셋의 크기와 목적에 따라 정합니다.
    
    |데이터셋 규모|권장 범위|비|
    |---|---|---|
    |작은 데이터(수천 문장)|500 ~ 2,000||
    |IMDB(50,000 리뷰)|5,000 ~ 10,000|공식 예제에서도 `10000` 사용. 튜토리얼은 100~500|
    |큰 뉴스 데이터|20,000 ~ 50,000||
    |LLM|수만~수십만 개 토큰||
    
- 리턴타입 : 중첩된 튜플로 반환

#### LSTM(Long Short-term Memory)

![[0916_3.png]]

세 가지 게이트가 있습니다.

|게이트|역할|
|---|---|
|Forget Gate|버릴 정보 결정|
|Input Gate|새 정보 저장|
|Output Gate|다음 단계로 전달|

이 덕분에 긴 문장도 비교적 잘 기억합니다.

### 출력

`LSTM(32)`는 마지막 시점의 은닉상태 하나를 출력합니다.

출력 크기

(32)(32)

(32)

즉 32개의 특징 벡터가 만들어집니다.

```python
model.add(keras.layers.LSTM(32, dropout=0.3, recurrent_dropout=0.3))
```

#### CNN + LSTM 혼합 모델

- CNN : 단어 묶음 특징 추출
- LSTM : 시간적 흐름 이해

![[0916_6.png]]

Conv1D로 지역적인 특징을 먼저 추출한 후 LSTM으로 문맥의 순서를 학습하는 구조

```python
# CNN + LSTM 혼합 모델

# CNN이 문장에서 5개 단어씩 묶어서 중요한 패턴을 찾습니다. LSTM이 처음부터 모든 단어를 읽으면 계산량이 많음
# Conv1D : 지역 패턴
# 필터갯수 : 32
# 커널크기 : 5(한 번에 5단어 확인
# 음수제거 : relu
model.add(keras.layers.Conv1D(32, 5, activation='relu'))
# 특징 맵을 절반으로 압축 -> 계산량 감소, 중요한 특징 유지, 과적합 감소
model.add(keras.layers.MaxPooling1D(2))
# CNN이 뽑은 특징들을 순서대로 읽으면서 문장의 전체 의미를 이해
model.add(keras.layers.LSTM(32))  # , dropout=0.3, recurrent_dropout=0.3
# 학습 중 뉴런의 30%를 랜덤하게 끕니다. -> 과적합(Overfitting)을 줄이기 위해서
model.add(keras.layers.Dropout(0.3))
```
