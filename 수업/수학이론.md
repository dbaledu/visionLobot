
##### 일차원함수, 이차원함수

|구분|1차원 함수 (일변수 함수)|2차원 함수 (이변수 함수)|
|---|---|---|
|**독립변수 개수**|1개 (\(x\))|2개 (\(x, y\))|
|**대표적인 식**|\(y = f(x)\)|\(z = f(x, y)\)|
|**그래프가 그려지는 공간**|2차원 좌표평면 (\(x, y\))|3차원 좌표공간 (\(x, y, z\))|
|**기하학적 형태**|선(직선, 곡선 등)|면(곡면 등)|

##### 일차함수, 이차함수
- 다항식의 최고차수(Degree)에 따른 차이
- '1차 함수', '2차 함수'라고 부르는 것은 **변수** \($x$\)**의 가장 높은 지수(차수)**를 의미합니다.
- 이는 변수의 차원이 아니라 식의 최고차항이 1차($x$)인지 2차$(x^{2})$인지에 따라 **직선**이 그려지는지 **포물선**이 그려지는지의 차이

| 구분         | 1차 함수 (Linear Function)         | 2차 함수 (Quadratic Function)             |
| ---------- | ------------------------------- | -------------------------------------- |
| **정의**     | 최고차수가 **1차**인 다항함수              | 최고차수가 **2차**인 다항함수                     |
| **일반식**    | $(y = ax + b \quad (a \neq 0))$ | $(y = ax^2 + bx + c \quad (a \neq 0))$ |
| **그래프 형태** | 끊임없이 뻗어나가는 **직선**               | 아래나 위로 볼록한 **포물선**                     |
| **기울기 특징** | 기울기(\(a\))가 항상 **일정함**          | 위치에 따라 기울기가 **계속 변함**                  |
| **극값**     | 극대값이나 극소값이 **없음**               | 꼭짓점에서 **최대값 또는 최소값**을 가짐               |

#### log
어떤 수를 만드기 위해 밑을 몇번 거듭제곱해야 하는지 구하는 지수의 역연산
- **기본 정의**: $b^c = a$ 일 때, $log_b a = c$로 나타냅니다 $(b > 0, b ≠ 1, a > 0)$.
	-   a=진수  b=밑  c=지수
- **상용로그**: 밑이 10인 로그로 $log x$와 같이 밑을 생략해 적습니다 $log_{10} 100 = 2$.
- **자연로그**: 밑이 무리수 e (약 2.718)인 로그로 $ln x$로 나타냅니다. 


#### 미분방정식
- **微(작을 미)** 와 **分(나눌 분)** : 미세하게 나눈다
- 수학에서 미분은 함수나 변화율을 다룰 때 어떤 양을 분간이 어려울 정도로 아주 작게 쪼갠다는 의미에서 유래
- 영어로는 '차이를 두다'라는 뜻의 `differentiation` 또는 `differential`


#### logit(로짓)
- **로그(log)**와 **오즈(odds, 승산)**의 합성어로, 통계학과 인공지능(AI)에서 **확률값을 실수 전체 범위(-∞ ~ +∞)로 변환한 값**
- 확률 p는 항상 0에서 1 사이의 값만 가지는데 로짓변환을 거치면 값의 범위가 -∞ ~ +∞ 까지로 확장.
- 로짓 값이 0이면 확률이 50%, 양수면 50%보다 높고 음수면 50%보다 낮음
- 로짓 함수를 거꾸로 되돌리는 함수가 시그모이드 함수
