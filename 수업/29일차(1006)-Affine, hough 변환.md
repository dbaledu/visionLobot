## Hough Line transform

[Hough transform](https://en.wikipedia.org/wiki/Hough_transform)

- 이미지에서 직선이나 원 같은 도형을 찾아내는 방법
- "여러 개의 에지 점들이 어떤 하나의 직선 위에 모여 있는지 찾아내는 방법”
- Canny를 적용하면 차선이 이런 식으로 **점(에지)**으로 나타납니다. 점들이 이어지는 하나의 직선을 찾아주는 것
- 일반적인 직선 표현은 y = ax + b → 직선인 경우에 기울기 a 가 무한대가 되어 표현하기 어려움

#### 사인, 코사인

- 사인함수의 함숫값은 단위원을 따라 x축으로부터 동경이 θ만큼 회전한 지점의 y좌표가 되며,
- 코사인함수의 함숫값은 단위원을 따라 x축으로부터 동경이 θ만큼 회전한 지점의 x좌표가 됩니다.
- 사인함수와 코사인함수의 함숫값은 -1에서 1사이의 값을 가짐.

```
     ● (x, y)
    /|
   / |
  /  | y
 /θ  |
/____|
    x
    
x = 가로 방향으로 얼마나 갔는가  => cos θ
y = 세로 방향으로 얼마나 갔는가  => sin θ

θ = 0°   ==>  cos 0° = 1,  sin 0° = 0   ==>   점의좌표 (1, 0)
θ = 90°  ==>  cos 90° = 0, sin 90° = 1  ==>   점의좌표 (0, 1)
```

#### 허프변환

```python
x0 = rho × cos(theta)
y0 = rho × sin(theta)
rho가 거리의 크기를 결정하고, cos(theta)와 sin(theta)가 
그 거리를 x방향과 y방향으로 나누어 주는 것
```

## 선형보간

- **두 점을 알고 있을 때 그 사이에 있는 어떤 위치의 값을 찾아내는 것**
- 두 점을 연결한 직선에서, 원하는 y 위치를 하나 정하면 그 위치의 x를 찾아주는 것
- y를 넣으면 차선의 x 위치를 알려주는 계산
- 차선 검출에서는 화면의 y = 400 위치에서 차선의 x가 어디인가?

```python
y
↑
│  ● (100,400)
│    \
│      \
│        \
│          ● (300,200)
│
└────────────────→ x

y가 두 점 사이에서 어느 정도 위치에 있는지를 보고, x도 그만큼 이동시키는 것

예시)
y=300 이면 200과 400 중간
x 도 100 과 300의 중간이면 x = 200
```

```python
두 점
  ↓
직선으로 연결
  ↓
원하는 y를 지정
  ↓
그 y에서 직선과 만나는 x를 찾음
  ↓
차선 가운데 찾기 
```
