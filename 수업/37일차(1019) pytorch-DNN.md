## PyTorch 모델 구조

![[pytorch01.png]]

- Sequential
        - 레이어를 순서대로 연결. 입력 데이터가 첫 번째 레이어를 통과하면, 그 결과가 자동으로 다음 레이어의 입력

- nn.Linear
        - 입력을 계산해서 새로운 특성 생성  
        - 출력 뉴런은 입력값에 가중치를 곱하고 편향을 더합니다.  
        - 기둥을 세움  

- Relu(Rectified Linear Unit)
        - 활성화 함수. 비선형성을 추가. 가중치 값을 보정하여 다음 레이어로 전달
        - ReLU(x)=max(0,x)  <- 입력이 음수면 0으로 바꾸고 양수면 그대로 통과

- LogSoftmax
        - 마지막 출력층에서 계산된 출력뉴런의 각 점수를 로그 확률로 변환

###### Softmax와 Logsoftmax와의 차이  

- Softmax는 출력 점수들을 0~1 사이의 확률로 바꾸며, 각 클래스 확률의 합이 1이 되도록 합니다.
- LogSoftmax는 이 확률에 로그를 적용한 결과로 로그 확률은 0 이하의 값이 되며, 값이 0에 가까울수록 해당 클래스의 확률이 높습니다.


## cv1019_1_pytorch_MNIST.ipynb

#### 파이프라인

###### **① 라이브러리 임포트**

- 딥러닝 모델 학습에 필수적인 PyTorch 프레임워크 핵심 패키지(`torch`, `nn`, `F`), 데이터셋 로드 및 전처리를 위한 `torchvision`, 그리고 학습 과정을 시각적으로 확인하기 위한 `tqdm`, `matplotlib` 등을 불러옵니다.

###### **② 데이터셋 다운로드 및 전처리**

- **MNIST 데이터셋**의 학습용(Train) 데이터 60,000장과 테스트용(Test) 데이터 10,000장을 다운로드합니다.
- 이 과정에서 `transforms.ToTensor()`를 통해 이미지 데이터를 0~255 범위의 픽셀 값에서 **0~1 사이의 범위를 갖는 PyTorch 텐서(Tensor)로 정규화**하며 변환합니다.

###### **③ 데이터 로더 구축**

- 60,000장의 전체 데이터를 한 번에 학습하면 메모리가 부족하고 효율성이 떨어지기 때문에, **100개씩 묶어서(Batch Size = 100) 모델에 공급**해 주는 `DataLoader`를 생성합니다.
- 학습 데이터는 모델의 과적합(Overfitting)을 방지하기 위해 매 에폭(Epoch)마다 데이터를 무작위로 섞도록(`shuffle=True`) 설정합니다.

###### **④ 데이터 확인 및 시각화**

- 실제 데이터가 어떻게 생겼는지 확인하기 위해 첫 번째 이미지 픽셀 값들을 출력해 보고, 2D 흑백 이미지(`cmap='gray'`)로 시각화합니다.
- 데이터 로더가 데이터를 `[배치 크기(100), 채널(1), 가로(28), 세로(28)]` 형태로 올바르게 반환하고 있는지 차원(Shape)을 체크합니다.

###### **⑤ 인공 신경망(ANN) 모델 정의**

- `nn.Sequential`을 사용하여 심층 신경망(Multi-Layer Perceptron, MLP)을 정의합니다.
    - **입력층**: $28 \times 28$$28 \times 28$ 크기의 2D 이미지를 1차원 벡터인 **784** 크기로 펼쳐서 입력받습니다.
    - **은닉층**: 128개의 뉴런을 가진 첫 번째 은닉층과 64개의 뉴런을 가진 두 번째 은닉층을 거치며 비선형 활성화 함수인 **ReLU**를 사용해 데이터의 복잡한 특징을 학습합니다.
    - **출력층**: 최종적으로 10개의 숫자(0~9) 클래스에 대응하는 **10** 크기의 출력을 내며, 다중 클래스 분류를 위해 **LogSoftmax**를 적용하여 각 숫자가 정답일 확률(로그 확률)을 계산합니다.

###### **⑥ 손실 함수 및 옵티마이저 설정 

- **손실 함수 (`CrossEntropyLoss`)**: 모델의 예측값과 실제 정답(Label) 사이의 오차를 계산하기 위해 다중 분류에 가장 적합한 크로스 엔트로피 손실 함수를 사용합니다.
- **옵티마이저 (`SGD`)**: 확률적 경사 하강법(Stochastic Gradient Descent)을 활용하여, 계산된 오차를 바탕으로 모델의 가중치(Weights)와 편향(Bias)을 효과적으로 수정(학습)하도록 합니다. (학습률 `lr = 0.09`)

###### **⑦ 모델 학습 (Training Loop)**

- 총 **15 에폭(Epochs)** 동안 학습을 반복합니다.
- 각 배치마다 가중치의 기울기(Gradient)를 초기화하고, **순전파(Forward)** 과정을 통해 예측값을 구한 뒤 손실(Loss)을 계산합니다.
- 이 손실을 바탕으로 **역전파(Backward, 오차역전파)**를 실행하여 각 레이어의 기울기를 구하고, 옵티마이저를 통해 가중치들을 업데이트(`optimizer.step()`)합니다.
- 출력 결과를 보면 에폭이 진행될수록 `Training loss`가 약 0.90에서 0.038까지 안정적으로 감소하며 모델이 정상적으로 학습되는 것을 볼 수 있습니다.

###### **⑧ 모델 평가 (Evaluation)**

- 학습이 완료된 모델의 실력을 검증하기 위해, 학습에 한 번도 사용되지 않은 10,000장의 **테스트 데이터셋**을 모델에 통과시킵니다.
- 평가 단계이므로 기울기를 계산하지 않도록 `torch.no_grad()` 환경 내에서 동작하며, 최종 예측값 중 가장 높은 확률을 가진 클래스(`torch.argmax`)와 실제 정답을 비교하여 정확도(Accuracy)를 누적합니다.
- 최종적으로 **97.69% (0.9769)**라는 높은 테스트 정확도를 달성하며 모델 구축이 완료되었음을 확인할 수 있습니다.

```python
# -*- coding: utf-8 -*-
"""cv1019_1_pytorch_MNIST.ipynb
  
Automatically generated by Colab.
  
Original file is located at
    https://colab.research.google.com/drive/1-RQnUUTN3TKlBi1Z1XrpJ-4L1_xVyhm6
"""
  
#---------------------------------
# 라이브러리 임포트
#---------------------------------  
import numpy as np
  
# PyTorch 프레임워크 메인 패키지
import torch
  
# 손실함수, 활성화 함수, 풀링등의 연산 제공
import torch.nn.functional as F
  
# 인공 신경만의 기본 구성 요소 (Linear, Conv2d, Loss함수, Sequential...)
import torch.nn as nn
  
# 컴퓨터 비전 작업을 위한 데이터셋, 모델 아키텍저 및 이미지 변환툴
from torchvision import datasets, transforms
  
# 주피터 노트북 환경에 최적화된 Progress bar 위젯
from tqdm.notebook import tqdm


#---------------------------------
# 2. 데이터셋 다운로드 및 전처리
#---------------------------------  
# transforms.ToTensor(): 이미지 정보(h,w,c)를 FloatTensor(c,h,w)로 변환 및 정규화 처리
mnist_train = datasets.MNIST(root='./datasets', train=True,
                             transform=transforms.ToTensor(), download=True)
mnist_test = datasets.MNIST(root='./datasets', train=False,
                            transform=transforms.ToTensor(), download=True)
  
#---------------------------------
# 3. 데이터 로더 구축
#---------------------------------   
# shuffle=True: epoch마다 데이터 순서를 무작위로 섞음 (과적합 방지)
train_loader = torch.utils.data.DataLoader(mnist_train, batch_size=100, shuffle=True)
  
# 테스트용이므로 무작위로 섞을 필요 없음
test_loader = torch.utils.data.DataLoader(mnist_test, batch_size=100, shuffle=False)
  
  
#---------------------------------
# 4. 데이터 확인 및 시각화
#---------------------------------     
import matplotlib.pyplot as plt

print(train_loader.dataset.data[0])
plt.imshow(train_loader.dataset.data[0].numpy(), cmap='gray')

print(type(train_loader))
image, label = train_loader.dataset[0]
print(image.shape)    # torch.Size([1, 28, 28])
print(label)

for images, labels in train_loader:
    print(type(images))
    print(type(labels))
    break

images, labels = next(iter(train_loader)) #  (image, label)  튜플

print(type(images))   # torch.Size([100, 1, 28, 28]) [] b,c,h,w]
print(images.shape)

print(type(labels))
print(labels.shape)
print('len(train_loader):', len(train_loader))  #600  <- 60000데이터 /100 배치


#---------------------------------
# 5. 인공 신경망(ANN) 모델 정의
#---------------------------------   
input_size = 784            # 입력층: 28x28 손글씨 이미지를 1차원 열벡터로 펼침
hidden_sizes = [128, 64]    # 1번째 은닉층: 128개, 2번째 은닉층: 64개
output_size = 10            # 출력층: 클래스 개수
  
model = nn.Sequential(
    # 입력층 -> 1번째 은닉층
    nn.Linear(input_size, hidden_sizes[0]),
    # 활성화 함수
    nn.ReLU(),
    # 1번째 은닉층 -> 2번째 은닉층
    nn.Linear(hidden_sizes[0], hidden_sizes[1]),
    nn.ReLU(),
    # 2번째 은닉층 -> 출력층
    nn.Linear(hidden_sizes[1], output_size),
    nn.LogSoftmax(dim=1)
)


#--------------------------------- 
# 6. 손실 함수 및 옵티마이저 설정
#---------------------------------   
# 다중 클래스 분류용 손실 함수
criterion = nn.CrossEntropyLoss()
  
# SGD(Stochastic Gradient Descent): 확률적 경사 하강법
# parameters: 신경망 내 모든 레이어의 학습 대상 가중치(w)와 bias(b) 전달
# lr(Learning Rate): 학습률
optimizer = torch.optim.SGD(model.parameters(), lr=0.09)
  
  
#--------------------------------- 
# 7. 모델 학습
#---------------------------------    
epochs = 15 # 총 15번 반복 학습
for e in range(epochs):
    running_loss = 0 # 1 epoch 동안 발생한 손실값
  
    # batch 동작
    for images, labels in train_loader:
        # 1차원 벡터로 변환
        images = images.view(images.shape[0], -1)
        # 기울기(Gradient) 초기화
        optimizer.zero_grad()
        # 순전파(Forward pass)
        output = model(images)
        # loss값 계산
        loss = criterion(output, labels)
        # 역전파(Backward pass)
        loss.backward()
        # 가중치 업데이트
        optimizer.step()
        # 손실값 누적 (순수 float scala값 추출)
        running_loss += loss.item()
    print(f"Epoch:{e} Training loss: {running_loss/len(train_loader)}")
    
#--------------------------------- 
# 8. 모델 테스트 및 평가 (Evaluation)
#---------------------------------      
correct = 0   # 모델이 맞춘 정답 이미지 누적 개수
total = len(mnist_test)

# 평가/추론 단계에서는 역전파을 사용하지 않으므로 no_grad() 사용
with torch.no_grad():
  for images, labels in tqdm(test_loader):     # 테스트데이터 10000개 / 100 배치크기  --> 100번
    # 1차원 벡터 처리.  신경망의 입력크기가 784. 각 픽셀을 1차원 백터로 변환
    # 이미지 64장의 개수는 유지하고, 각 이미지의 픽셀 784개를 한 줄로 펼쳐 신경망에 입력하는 코드입니다.
    x = images.view(images.shape[0], -1)  # torch.Size([100, 1, 28, 28])  -->  torch.Size([100, 784])
    # 테스트 이미지 예측값
    y = model(x)
    # 최종 예측 클래스. 모델이 출력한 값 중에서 가장 큰 값의 위치(인덱스)를 찾아 예측 클래스 번호를 구하는 코드
    predictions = torch.argmax(y, dim=1)
    # 정답 판별 및 누적
    correct += torch.sum(predictions == labels).item()

print(f'Test accrracy:{correct/total}')
    
```

## cv1019_2_pytorch_DNN-FashionMNIST.ipynb

#### 파이프라인

###### 1. 라이브러리 임포트 및 개발 환경 설정

- **목적:** 딥러닝 모델 개발에 필요한 PyTorch 핵심 모듈(`torch.nn`, `DataLoader`), 데이터셋 도구(`torchvision.datasets`), 시각화 도구(`matplotlib`) 등을 불러옵니다.

###### 2. 데이터셋 로드

- **목적:** PyTorch 내장 데이터셋 기능을 이용해 `FashionMNIST` 이미지 데이터(28x28 픽셀의 의류 이미지 10종)를 다운로드하고, 이미지 데이터를 PyTorch 텐서 형식(`ToTensor()`)으로 변환합니다.
- 학습용 데이터(`train=True`)와 평가용 데이터(`train=False`)로 분리하여 저장합니다.

###### 3. 데이터 로더 구성 및 연산 장치 설정

- **목적:** 데이터를 지정한 배치 크기(여기서는 64개)로 묶어 모델에 안정적으로 공급해줄 수 있는 `DataLoader`를 생성합니다.
- 또한, 연산 속도를 높이기 위해 CUDA(Nvidia GPU)나 MPS(Apple Silicon GPU)가 사용 가능한지 확인하고 적절한 연산 장치(`device`)를 지정합니다.
- _참고: `DataLoader`가 정의되지 않았다는 에러(`NameError`)가 발생한 적이 있는데, 이는 1번 셀(임포트 셀)을 먼저 실행하지 않았거나 실행 순서가 꼬여서 발생한 문제이므로 1번 셀을 다시 실행해주시면 해결됩니다._

###### 4. 신경망 모델 설계 및 인스턴스화

- **목적:** `nn.Module`을 상속받아 3개의 선형 계층(`nn.Linear`)과 활성화 함수(`nn.ReLU`, 출력층의 `LogSoftmax`)로 이루어진 간단한 다층 퍼셉트론(MLP) 분류 모델을 설계합니다.
- 28x28 크기의 2차원 이미지를 784 크기의 1차원 벡터로 변환(`Flatten`)한 뒤 입력받아 최종적으로 10개의 클래스(의류 카테고리)에 대한 확률값을 출력합니다. 모델 객체를 생성하여 GPU/CPU 장치로 이동시킵니다.

###### 5. 손실 함수, 최적화 알고리즘 정의 및 학습/평가 루프 수행 

- **목적:** 다중 클래스 분류를 위한 크로스 엔트로피 손실 함수(`CrossEntropyLoss`)와 경사하강법 옵티마이저(`SGD`)를 설정합니다.
- **학습 함수(`train`):** 데이터를 배치 단위로 모델에 주입하여 예측값을 얻고, 손실을 계산한 뒤 역전파(`loss.backward()`)와 가중치 업데이트(`optimizer.step()`)를 반복하여 모델을 최적화합니다.
- **평가 함수(`test`):** 가중치 업데이트 없이 평가 모드(`model.eval()`)에서 테스트 데이터의 평균 손실값과 정확도를 계산합니다.
- 총 5번의 Epoch 동안 이 과정을 반복하며 모델의 성능을 향상시킵니다.

###### 6. 학습된 모델 저장 및 다시 불러오기 

- **목적:** 학습이 완료된 모델의 파라미터(가중치와 편향 값들, `state_dict`)를 파일(`model.pth`)로 저장합니다.
- 프로그램이 종료되거나 다른 곳에서 모델을 재사용할 때, 구조가 동일한 새 모델 객체를 만들고 저장된 파일에서 파라미터를 로드(`load_state_dict`)하여 학습 상태를 그대로 복원할 수 있음을 검증합니다.

###### 7. 로드된 모델로 개별 이미지 분류 예측 및 검증 

- **목적:** 다시 불러온 모델을 평가 모드로 전환하고, 실제 테스트 세트에서 개별 이미지를 무작위로 꺼내어 모델이 올바르게 카테고리를 예측하는지 눈으로 직접 확인합니다.
- 10개의 예시 이미지에 대해 실제 값(`actual_class`)과 모델의 예측 값(`pred_class`)을 비교 출력하여 일치 여부(`O`/`X`)를 판단합니다.

```python
# -*- coding: utf-8 -*-
"""cv1019_2_pytorch_DNN-FashionMNIST.ipynb

Automatically generated by Colab.

Original file is located at
    https://colab.research.google.com/drive/1NWIHKmU92YJ5tEctM4CUAdKPwvVSC1ND
"""

import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import ToTensor, Lambda, Compose
import matplotlib.pyplot as plt

#---------------------------------
#FashinMNIST 데이터셋 로드
#---------------------------------
training_data = datasets.FashionMNIST(root="data",     # 다운로드 폴더 위치
                                      train=True,
                                      download=True,
                                      transform=ToTensor())
test_data = datasets.FashionMNIST(root="data",
                                  train=False,
                                  download=True,
                                  transform=ToTensor())

batch_size = 64
train_dataloader = DataLoader(training_data, batch_size=batch_size)
test_dataloader = DataLoader(test_data, batch_size=batch_size)

for X, y in test_dataloader:
  print(f'Shape of X[N,C,H,W]: {X.shape}')
  print(f'Shape of y: {y.shape}, {y.dtype}')
  break

# 사용할 연산 장치 설정
device = (
    'cuda' if torch.cuda.is_available() else # nvidia GPU
    'mps' if torch.backends.mps.is_available() else # Apple silicon GPU
    'cpu'
)
print(f'Using {device} device')

#---------------------------------
# nn.module을 상속받아 커스텀 다층 퍼셉트론(MLP) 신경망 클래스 정의
#---------------------------------
class Neuralnetwork(nn.Module):
  def __init__(self):
    # 부모 클래스 생성
    super().__init__()
    # 1차원 벡터로 변환
    self.flatten = nn.Flatten()
    self.linear_relu_stack = nn.Sequential(
      nn.Linear(28*28, 512), nn.ReLU(),            # 입력층  -> 은닉층1
      nn.Linear(512, 512),   nn.ReLU(),            # 은닉층1 -> 은닉층2
      nn.Linear(512, 10),    nn.LogSoftmax(dim=1)  # 은닉층2 -> 출력층
    )

  # 오버라이딩
  def forward(self, x):
    x = self.flatten(x)
    # 선형 계층 및 활성화 함수 스택 처리
    logits = self.linear_relu_stack(x)
    return logits


# 모델의 파라미터 등을 해당 장치로 이동
model = Neuralnetwork().to(device)  #CPU와 GPU 이동.

from torch._higher_order_ops.wrap import proxy_mode_key
# 손실 함수
loss_fn = nn.CrossEntropyLoss()

# 가중치 최적화
optimizer = torch.optim.SGD(model.parameters(), lr=1e-3)

#---------------------------------
# 학습 함수 정의
#---------------------------------
def train(dataloader, model, loss_fn, optimizer):
  # 전체 학습데이터
  size = len(dataloader.dataset)
  # batch: 배치 번호
  #(x, y): 입력 데이터, 정답
  for batch, (X, y) in enumerate(dataloader):
    X, y = X.to(device), y.to(device)    # 데이터를 모델이 있는 연산 장치로 복사
    pred = model(X)                      # 순전파 모델에 입력 전달   forward() 함수 호출
    loss = loss_fn(pred, y)              # 손실 계산
    loss.backward()                      # 역전파
    optimizer.step()                     # 가중치 업데이트
    optimizer.zero_grad()                # 기울기 초기화(다음 배치를 위해 0으로 리셋)
    if batch % 100 == 0:                 # 현재 손실값과 학습 진행 상태 출력
      loss, current = loss.item(), batch * len(X)
      print(f'loss:{loss:>5f}  {current/size}')


#---------------------------------
# 테스트 및 검증 함수 정의
#---------------------------------
def test(dataloader, model, loss_fn):
  size = len(dataloader)         # 전체 테스트데이터
  num_batches = len(dataloader.dataset)    # 테스트 배치 총 개수
  model.eval()                             # 모델을 평가 (Evaluation) 모드로 전환
  test_loss, correct = 0, 0                # 테스트 누적 손실값, 정답 개수
  with torch.no_grad():                    # 평가시에는 가중치 업데이트 필요 없음
    # 배치
    for X, y in dataloader:
      X, y = X.to(device), y.to(device)
      pred = model(X)                      # 테스트 데이터 예측값 처리
      test_loss += loss_fn(pred, y).item()  # 손실값을 float 스칼라로 추출하여 누적
      correct += (pred.argmax(1) == y).type(torch.float).sum().item()
  test_loss /= num_batches                 # 평균 손실값(전체 누적 손실값 / 배치 개수)
  correct /= size                          # 정확도(맞춘개수/전체 샘플 개수)
  print(f'Accuracy:{100*correct}% Avg loss:{test_loss}')
  print(correct, size, test_loss)


epochs = 5
for t in range(epochs):
  print(f'Epoch {t+1}\n---------------------------------')
  train(train_dataloader, model, loss_fn, optimizer )
  test(test_dataloader, model, loss_fn)

torch.save(model.state_dict(), 'model.pth') #학습된 파라미터(w,b)를 딕셔너리로 저장
print('saved PyTorch Model state model.pth')

# 저장된 모델 불러오기
model = Neuralnetwork().to(device)
model.load_state_dict(torch.load('model.pth'))

# 테스트 데이터 첫번째 하나만 예측해보기
classes = ['T-shirt/top','Trouser','Pullover','Dress','Coat','Sandal','Shirt','Sneaker','Bag','Ankle boot']
model.eval()  # 모델을 평가모드로 변환
# x 이미지 텐서
# y 정답(0~9)
x, y = test_data[0][0], test_data[0][1]   #( 독립변수(이미지), 라벨)
with torch.no_grad():
  x = x.to(device)
  pred = model(x)
  # 예측값, 실제
  predicted, actual = classes[pred[0].argmax(0)], classes[y]
  print(f'predicted:{predicted}, actual:{actual}')

for i in range(10):
  x_i, y_i = test_data[i][0], test_data[i][1]
  x_i = x_i.to(device)
  pred_i = model( x_i )   # 출력변수 10개의 값
  pred_class = classes[pred_i[0].argmax(0)]   # 출력결과중에서 제일 확률이 큰 인덱스
  actual_class = classes[y_i]
  is_correct = '0' if pred_class == actual_class else 'X'
  print(f'[{i+1}/10]:[{is_correct}] pred_class:{pred_class} \t actual_class:{actual_class}')

```
