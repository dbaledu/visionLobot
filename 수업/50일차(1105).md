#### 보드 주요 구성 요소

|구성 요소|역할|자율주행 활용|
|---|---|---|
|CPU|ARM Cortex-A57 쿼드코어|Python, ROS 실행|
|GPU|128-core Maxwell GPU|OpenCV, CUDA, YOLO|
|RAM|4GB LPDDR4|영상 및 AI 모델 처리|
|microSD|운영체제 및 데이터 저장|Ubuntu, JetPack|
|CSI 카메라|MIPI 카메라 입력|전방 카메라|
|USB 3.0|외부 USB 장치 연결|USB 카메라|
|HDMI|모니터 출력|영상 및 결과 확인|
|Ethernet|유선 네트워크|ROS 통신, 원격 접속|
|40핀 헤더|GPIO 및 통신 인터페이스|센서, 모터 제어|
|Fan Header|냉각팬 제어|온도 관리|

##### IP 설정
- 노트북 와이파이망과 동일하게 선택
- 
```shell
# 주변 Wi-Fi 목록 검색
$ nmcli dev wifi list

# Wi-Fi 연결
sudo nmcli dev wifi connect "와이파이_이름" password "비밀번호"

# 연결 확인 (선택 사항)
$ ping -c 4 8.8.8.8

# IP 주소 확인하기
$ ifconfig wlan0

$ ntu 1500
# wlan0 ip 확인
```
