- 포지셔널 인코딩

## 멀티 헤드 어텐션

하나의 어텐션만 사용하면 한 가지 관점만 잘 볼 수 있지만, 여러 개를 사용하면 다양한 패턴을 동시에 학습할 수 있습니다.

![[0917_1.png]]

입력 문장이 들어오면 각 Head는 독립적으로 Self-Attention을 수행하고, 마지막에 결과를 합쳐(Concatenate) 선형 변환(Linear Layer)을 거쳐 다음 층으로 전달합니다.

#### 왜 여러 개(Head)가 필요할까?

문장에서 단어는 여러 종류의 관계를 가집니다.

> "The robot follows the car because it is moving."

여기서 `it`이 무엇을 가리키는지 판단하려면 여러 관계를 동시에 봐야 합니다.

- Head 1: 문법 관계(주어·목적어)
- Head 2: 의미 관계(누가 움직이는가)
- Head 3: 거리 관계(가까운 단어)
- Head 4: 문맥 관계

## GPT

GPT의 풀네임은 Generative Pre-trained Transformer 입니다.

트랜스포머를 공부하는 입장이라면 이름 자체가 모델의 특징을 잘 설명하고 있어서 단어별 의미를 이해하는 것이 중요합니다.

|약어|풀네임|의미|
|---|---|---|
|G|Generative|새로운 텍스트를 생성하는 모델|
|P|Pre-trained|대량의 데이터로 미리 학습된 모델|
|T|Transformer|트랜스포머 구조(Attention 기반)를 사용하는 모델|

#### 각 단어를 쉽게 이해하면

- Generative(제너러티브, /ˈdʒenərətɪv/): 단어를 예측하면서 문장을 만들어내는 능력입니다.
- Pre-trained(프리 트레인드): 인터넷 문서, 책, 위키 등의 방대한 데이터를 먼저 학습한 뒤 다양한 작업에 활용합니다.
- Transformer(트랜스포머): 2017년 구글의 논문 **"Attention Is All You Need"**에서 제안된 신경망 구조로, 문장 전체의 단어 관계를 Self-Attention으로 동시에 파악합니다.

## 시계열 실습

| 단계        | 코드                    | 설명                    |
| --------- | --------------------- | --------------------- |
| 데이터 로드    | `pd.read_csv()`       |                       |
| 컬럼 선택     | `df["T (degC)"]`      |                       |
| 정규화       | `StandardScaler`      | 스케일링 데이터에서 더 안정적으로 학습 |
| Window 생성 | `for`문                |                       |
| 데이터 분리    | 시간 순서 유지              |                       |
| 모델 생성     | `Sequential()`        |                       |
| LSTM      | `layers.LSTM(32)`     |                       |
| Dropout   | `layers.Dropout(0.3)` |                       |
| 출력        | `Dense(1)`            |                       |
| 컴파일       | `optimizer="adam"`    |                       |
| 학습        | `fit()`               |                       |
| 예측        | `predict()`           |                       |
| 복원        | `inverse_transform()` |                       |
| 시각화       | `plt.plot()`          |                       |
