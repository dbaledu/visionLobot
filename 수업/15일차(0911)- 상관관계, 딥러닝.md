### 딥러닝

#### 인공신경망

- 입력층, 은닉층, 출력층 → Dense(기둥)

#### 딥러닝 구조

- 구성요소
    - 층
    - 가중치
    - 바이어스 : = 절편
    - 활성화 함수
        - 신호를 받아 처리하고 출력
        - 시그모이드, 하이퍼볼릭 탄젠트, 렐루(ReLU)
        - 비선형 함수
    - 손실 함수
        - 순전파, 역전파 반복하면서 오차율를 줄여나감
    - 전달함수

#### 활성화함수

- 시그모이드 함수
    - 선형함수 → 0~1 사이의 비선형 형태로 변형
    - 모델이 깊어지면 기울기가 소멸되는 문제 발생
- 렐루
    - 음수면 0, 양수일 때 X
    - `은닉층`에서 주로 사용
    - 경사하강법에 영향을 주지 않아 학습속도가 빠르고 기울기 소멸 문제가 발생하지 않음
- 리키 렐루
    - 음수이면 0을 출력 → 학습능력 감소
    - 해결책을 리키렐루 사용
- 소트프맥스 함수
    - `출력층`에서 사용하는 활성화 함수
    - 출력값들의 총합이 항상 1

#### 손실함수

- 오차를 구하는 방법
- 오차를 최소화하는 방향으로 이동시키는 방법
- 0에 가까우면 완벽하게 추정할 수 있다는 의미

#### MSE(평균제곱오차)

- 실제값과 예측값의 차이를 제곱하여 평균
- 회귀에서 손실함수로 주로 사용
- 텐서플로에서는 optimizer 인수에 사용

#### 크로스 엔트로피 오차

- 분류 문제에서 원핫인코딩에서만 사용
- 지역최소점에서 멈출 수 있음 → 로그 이용

#### 아담

#### 지역최소점 과 전역최소점

- 지역최소점
- 전역최소점 : 지역최소짐 중에서 가장 작은 값

입력 → 가중치 → 가중합 → 활성화함수 → 출력

#### 역전파 :

- 실제값과 예측값이 다르면(손실(오류)이 계산되면 가중치 업데이트
- 역으로 전파(출력→은닉→입력층))
- 예측값과 실제값 차이를 각 뉴런의 ㄱ중치롤 미분한 수 기존 가중치 값에서 뺌
- 역전파 결과값을 다시 순전파의 가중치 로 사용

#### 은닉층이 분류에 미치는 영향

- 활성화 함수가 적용된 은닉층 개수가 많을 수록 데이터 분류가 잘됨. 무조건 많다고 해서 좋은 건 아님
- 특성이 적으면 은닉층이 3개 정도면 됨

#### 은닉층이 많을수록 문제점 발생

- 과적합 발생
    - 훈련데이터에서는 성능이 잘 나왔지만 테스트 데이터는 낮음
    - 해결책
        - 드롭아웃 : 임의의 일부 노드를 학습에서 제외
- 기울기 소멸 문제 발생
    - 출력층에서 은닉층으로 전달되는 오차가 줄어들어 학습이 되지 않는 현상
    - 해결책 : 렐루 활성화 함수 이용
- 성능이 나빠지는 문제 발생
    - 경사하강법은 손실 함수의 비용이 최소가 된느 지점을 찾을 때까지 기울기가 낮은 쪽으로 계속 이동시키는 과정을 반복하는데 이때 성능이 나빠지는 문제가 발생
    - 가중치 와 오차 그래프
    - 미분 - 변화량
    - 해결책
        - 확률적 경사하강법 또는 미니 배치 경사하강법 사용
            - 배치 - 전체 데이터셋
            - 미니 배치 - 전체 데이터셋을 미니로 나누고 각각 …
- 해결책 : 옵티마이저 : 학습속도와 운동량(모멘텀) 조정
- 텐서플로우에서는 아담을 사용
